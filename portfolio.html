Unreal Engine Game Development

This project was my NEA (non-exam assessment) for A-Level Computer Science; I completed it entirely on my own and was awarded an A. It is a movement-focused melee game built from scratch in Unreal Engine using only C++ (no Blueprints).

  • Single-author project — designed and implemented all gameplay systems and assets myself.
  • Movement & animation: 8-directional movement with animation blending that adapts to player orientation, producing smooth and responsive transitions.
  • Advanced mechanics: bunny-hopping (bhop), a grapple mechanic, and the ability to attack while in motion.
  • Interactive environment: multiple grapple interactions (swinging, anchoring, and release mechanics) and moving terrain elements that affect traversal and combat, integrated with the game's physics and player controls.

To complete this project I self-taught C++ and the core workflows of Unreal Engine, relying on tutorial videos and C++ courses to learn new techniques and implement AAA-style mechanics and polish.
