Unreal Engine Game Development

This project was my NEA (non-exam assessment) for A-Level Computer Science; I completed it entirely on my own and was awarded an A. It is a movement-focused melee game built from scratch in Unreal Engine using only C++ (no Blueprints).

  • Single-author project — designed and implemented all gameplay systems and assets myself.
  • Movement & animation: 8-directional movement with animation blending that adapts to player orientation.
  • Advanced mechanics: bunny-hopping, grappling, and attacking while in motion.
  • Interactive environment with physics-based grapple interactions and moving terrain elements.

I self-taught C++ and Unreal Engine workflows, relying on documentation, tutorials, and experimentation to implement advanced mechanics and polish.
